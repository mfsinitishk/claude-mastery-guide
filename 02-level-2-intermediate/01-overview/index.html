    Level 2: Intermediate Engineering Workflows - Overview¶

    From Individual Tasks to Repository-Scale Development¶

    🎯 Level Overview¶

    Level 2: Intermediate Engineering Workflows elevates you from single-file, task-focused development to repository-scale engineering. This level transforms you from someone who uses Claude for individual coding tasks into a developer who orchestrates complex, multi-file features and collaborates effectively with teams using AI assistance.

    This is where AI-assisted development becomes truly powerful. You'll learn to work with entire codebases, coordinate changes across multiple files, analyze architecture, implement complete features, and integrate seamlessly with team workflows including Git, pull requests, and code reviews.

    By completing this level, you'll be equipped to handle real-world software engineering with AI assistance at a professional level.

    📋 Prerequisites¶

    Required (from Level 1): - ✅ Consistent ability to write effective prompts - ✅ Comfortable with basic AI-assisted coding workflows - ✅ Experience managing context in conversations - ✅ Understanding of Claude's capabilities and limitations - ✅ Established daily AI workflow for individual tasks - ✅ Completed Level 1 Assessment with passing score

    Technical Requirements: - Git knowledge (branching, commits, merging, PRs) - Experience with at least one backend or frontend framework - Understanding of REST APIs or GraphQL - Familiarity with testing frameworks - Command-line proficiency - IDE setup with git integration

    Helpful but not required: - Experience with CI/CD pipelines - Architectural design knowledge - Code review experience - Team development experience - Docker/containerization basics

    ⏱️ Time Commitment¶

    Total Time: 4-6 weeks for comprehensive mastery
    Minimum Time: 3-4 weeks for core competency
    Daily Commitment: 2-3 hours of focused learning and practice

    Breakdown: - Reading and concepts: 15-20 hours - Hands-on practice: 30-40 hours - Repository workflows: 15-20 hours - Real-world feature development: 20-30 hours - Code review and collaboration: 10-15 hours

    Weekly Structure: - Week 1: Repository workflows and multi-file operations - Week 2: Architecture analysis and Git workflows - Week 3: Feature development and testing strategies - Week 4: API development and full-stack patterns - Week 5: CLI workflows and advanced context management - Week 6: Advanced prompting and assessment

    🎓 Learning Objectives¶

    By the end of Level 2, you will be able to:

    Repository-Scale Development¶

    Repository Understanding: - ✅ Analyze entire repository structure and architecture - ✅ Navigate large codebases efficiently with AI assistance - ✅ Understand dependencies and relationships across files - ✅ Identify architectural patterns and design decisions - ✅ Create architectural documentation and diagrams

    Multi-File Workflows: - ✅ Coordinate changes across multiple files simultaneously - ✅ Maintain consistency across related components - ✅ Refactor with repository-wide impact analysis - ✅ Implement features that span multiple layers - ✅ Manage complex dependencies between files

    Feature Development and Testing¶

    End-to-End Features: - ✅ Design complete features from requirements - ✅ Implement backend services and APIs - ✅ Build frontend components and integrations - ✅ Create comprehensive test coverage - ✅ Document features thoroughly - ✅ Handle edge cases and error scenarios

    Testing Strategy: - ✅ Design test plans for complex features - ✅ Generate unit, integration, and E2E tests - ✅ Create test data and fixtures - ✅ Implement mocking strategies - ✅ Achieve and maintain high test coverage - ✅ Write testable, maintainable code

    Git and Collaboration¶

    Git Workflows: - ✅ Create well-structured commits with AI assistance - ✅ Write clear commit messages and PR descriptions - ✅ Manage feature branches effectively - ✅ Resolve merge conflicts with context awareness - ✅ Use git hooks and automation

    Code Review: - ✅ Review pull requests comprehensively with AI help - ✅ Identify issues, bugs, and improvements - ✅ Provide constructive feedback - ✅ Understand others' code quickly - ✅ Ensure code quality standards

    API and Full-Stack Development¶

    Backend Development: - ✅ Design RESTful and GraphQL APIs - ✅ Implement business logic and data models - ✅ Handle authentication and authorization - ✅ Optimize database queries - ✅ Implement caching strategies - ✅ Create API documentation

    Full-Stack Integration: - ✅ Connect frontend and backend components - ✅ Implement state management - ✅ Handle asynchronous operations - ✅ Manage API contracts - ✅ Debug full-stack issues - ✅ Optimize performance end-to-end

    Advanced Prompting and Context¶

    Context Optimization: - ✅ Provide minimal, effective context for large codebases - ✅ Use file trees and summaries strategically - ✅ Manage conversation length for complex tasks - ✅ Reference multiple files efficiently - ✅ Maintain focus across multi-step workflows

    Structured Prompting: - ✅ Create prompt templates for common workflows - ✅ Build reusable prompt patterns - ✅ Chain prompts for complex outcomes - ✅ Use conditional and iterative prompting - ✅ Optimize prompts for specific use cases

    1. Multi-File Workflows - 4-5 hours

    3. Impact analysis across files
    4. Maintaining consistency

    6. Architectural Analysis - 4-5 hours

    7. Understanding architecture patterns
    8. Analyzing design decisions
    9. Identifying dependencies
    10. Creating architecture documentation

    Outcome: Confidently work with entire repositories and coordinate multi-file changes

    Part 2: Git and Collaboration (Week 2)¶

    Time: 12-15 hours

    Sections: 4. Git Workflows - 4-5 hours - AI-assisted commits and messages - Branch management - Merge conflict resolution - Git automation and hooks

    1. PR Review Workflows - 4-5 hours
    2. Reviewing pull requests with AI
    3. Code quality analysis
    4. Suggesting improvements

    5. Writing review feedback

    6. Feature Development - 4-5 hours

    8. Feature planning and design
    9. Breaking down epics

    Outcome: Master team collaboration workflows with AI assistance

    Part 3: Testing and API Development (Week 3)¶

    Time: 12-15 hours

    Sections: 7. Test Strategy - 4-5 hours - Test planning and coverage - Unit, integration, E2E strategies - Test data generation - Mocking and stubbing

    1. API Development - 4-5 hours
    2. REST API design and implementation
    3. GraphQL API development

    5. Authentication and authorization

    7. Full-stack feature development
    8. Frontend-backend integration

    Outcome: Build complete, well-tested features with robust APIs

    Part 4: CLI and Advanced Workflows (Week 4)¶

    Time: 10-12 hours

    Sections: 10. Claude Code Usage - 3-4 hours - Deep dive into Claude Code CLI - Advanced CLI features - Automation with CLI - CLI best practices

    1. CLI Workflows - 3-4 hours

      • Command-line automation
      • Scripting with AI assistance
      • Shell integration
      • Building CLI tools

      • Advanced context management
      • Minimizing token usage

      • Collaborative coding with AI

      • Design discussions with AI

    3. Exercises and Examples - 4-5 hours

      • Intermediate-level exercises
      • Real-world project examples
      • Practice scenarios
      • Troubleshooting challenges

    4. Assessment - 2-3 hours

      • Level 2 competency evaluation
      • Skills validation
      • Level 3 readiness check
      • Gap analysis and planning

    Outcome: Master advanced prompting and validate Level 2 competency

    📊 Success Criteria¶

    Knowledge Validation¶

    By the end of Level 2, you should be able to:

    Repository Workflows: - [ ] Analyze and understand a new repository in under 30 minutes - [ ] Navigate efficiently to relevant code across large codebases - [ ] Identify architectural patterns and conventions - [ ] Create repository documentation and diagrams - [ ] Onboard new developers with AI-generated guides

    Multi-File Development: - [ ] Implement features spanning 5+ files simultaneously - [ ] Maintain consistency across related components - [ ] Perform repository-wide refactoring safely - [ ] Analyze impact of changes across codebase - [ ] Coordinate frontend, backend, and test changes

    Feature Development: - [ ] Design complete features from requirements - [ ] Implement end-to-end functionality - [ ] Create comprehensive test coverage (80%+) - [ ] Write complete API documentation - [ ] Handle edge cases and error scenarios

    Git and Collaboration: - [ ] Create well-structured, atomic commits - [ ] Write clear commit messages and PR descriptions - [ ] Review PRs comprehensively in under 15 minutes - [ ] Provide constructive, actionable feedback - [ ] Resolve merge conflicts efficiently

    API Development: - [ ] Design RESTful APIs following best practices - [ ] Implement GraphQL schemas and resolvers - [ ] Create comprehensive API tests - [ ] Document APIs with OpenAPI/GraphQL schemas - [ ] Implement authentication and authorization

    Context and Prompting: - [ ] Provide minimal, effective context for any task - [ ] Use prompt templates for common workflows - [ ] Chain prompts for complex multi-step tasks - [ ] Maintain conversation focus across 20+ exchanges - [ ] Optimize prompts for specific use cases

    Daily Development: - Implement features across full stack - Write comprehensive tests - Create documentation - Review team members' code

    Requirements Analysis: - Understand business requirements - Analyze technical constraints - Design solution architecture - Create technical specifications

    Implementation: - Set up feature branch - Implement backend services - Build frontend components - Write comprehensive tests - Create documentation

    Review and Deployment: - Self-review with AI assistance - Submit pull request - Address review feedback - Merge and deploy - Monitor production

    Team Collaboration Scenarios¶

    Code Review: - Review teammates' PRs quickly - Provide constructive feedback - Learn from others' approaches - Maintain code quality

    Problem Solving: - Debug complex issues collaboratively - Design solutions together - Analyze production incidents - Implement fixes

    🚧 Common Challenges and Solutions¶

    Challenge 1: Context Overload in Large Repos¶

    Problem: Conversations become unfocused with too much code context
    Solution: Use summaries, file trees, and targeted context
    Section: Context Optimization

    Challenge 2: Inconsistent Multi-File Changes¶

    Problem: Changes across files don't align or break integration
    Solution: Plan changes, use checklists, validate integration
    Section: Multi-File Workflows

    Challenge 3: Poor API Design¶

    Problem: APIs don't follow REST/GraphQL best practices
    Solution: Use design patterns, review with AI, follow standards
    Section: API Development

    Challenge 4: Inadequate Test Coverage¶

    Problem: Tests miss edge cases or don't cover critical paths
    Solution: Strategic test planning, coverage analysis
    Section: Test Strategy

    Challenge 5: Unclear Commit History¶

    Problem: Commit messages lack context, commits too large/small
    Solution: Follow commit conventions, use AI for messages
    Section: Git Workflows

    Challenge 6: Slow Code Reviews¶

    Problem: PRs take too long to review thoroughly
    Solution: AI-assisted review, automated checks, review templates
    Section: PR Review Workflows

    💡 Learning Tips¶

    Maximize Your Learning¶

    Work with Real Codebases: - Use your company's actual repositories - Contribute to open source projects - Analyze popular GitHub repositories - Practice with diverse tech stacks

    Build Complete Features: - Don't just write code snippets - Implement end-to-end functionality - Include tests and documentation - Deploy and monitor features

    Collaborate with Teams: - Review real pull requests - Participate in code reviews - Share knowledge with teammates - Learn from senior developers

    Measure Progress: - Track feature completion time - Measure test coverage trends - Monitor code review quality - Document productivity improvements

    Deliberate Practice Approach¶

    Weekly Focus Areas: - Week 1: Focus on repository understanding - Week 2: Master Git and collaboration - Week 3: Perfect testing and API design - Week 4: Optimize CLI and context workflows - Week 5-6: Advanced prompting and integration

    Daily Practice Routine: 1. Review previous day's learnings (10 min) 2. Study new concept/technique (30-45 min) 3. Practice with real code (60-90 min) 4. Reflect and document learnings (15 min)

    Reflection Questions: - What worked well today? - What challenges did I face? - How can I improve tomorrow? - What should I practice more?
