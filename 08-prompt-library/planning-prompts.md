# Planning Prompts

Prompts for project planning, estimation, and technical decision-making.

### 1. Project Planning
```
Plan project for [description]

Include: scope, milestones, deliverables, timeline, resources, risks, dependencies.
```

### 2. Feature Design
```
Design feature: [description]
Requirements: [list requirements]

Provide: architecture, API design, data model, implementation plan, testing strategy.
```

### 3. Technical Spike
```
Research [technology/approach] for [use case]

Evaluate: feasibility, pros/cons, alternatives, implementation complexity, recommendation.
```

### 4. Estimation
```
Estimate effort for [task]

Consider: complexity, unknowns, dependencies, team experience.
Provide: optimistic/realistic/pessimistic estimates.
```

### 5. Risk Assessment
```
Assess risks for [project/feature]

Identify: technical risks, business risks, mitigation strategies, contingency plans.
```

### 6. Technology Selection
```
Select technology for [use case]

Evaluate: requirements, alternatives, pros/cons, team expertise, long-term viability.
```

### 7. Roadmap Planning
```
Create roadmap for [project]

Include: phases, milestones, dependencies, resource allocation, timeline.
```

### 8. Sprint Planning
```
Plan sprint: capacity [X hours], priority features [list]

Assign: user stories to sprint, estimate story points, identify blockers.
```
