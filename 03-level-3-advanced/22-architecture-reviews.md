# Architecture Reviews

## AI-Assisted Code Architecture Analysis

---

## 🎯 Overview

Use Claude to review system architecture, identify issues, and suggest improvements for scalability, maintainability, and performance.

**Time to Master:** 3 hours

---

## 🔧 Review Areas

**System Design:** Component boundaries, data flow, dependencies  
**Scalability:** Bottlenecks, single points of failure  
**Maintainability:** Code organization, coupling, cohesion  
**Security:** Attack surfaces, data protection  
**Performance:** Efficiency, caching strategies
