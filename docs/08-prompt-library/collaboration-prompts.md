# Collaboration Prompts

Prompts for team collaboration, code reviews, and knowledge sharing.

### 1. Code Review Request
```
Review this PR: [title and description]
Changes: [summary]

Check: correctness, design, tests, documentation, performance, security.
Provide: actionable feedback, approval recommendation.
```

### 2. Onboarding Documentation
```
Create onboarding guide for [project/codebase]

Include: setup, architecture overview, development workflow, testing, deployment.
```

### 3. Technical Discussion
```
Discuss approach for [problem]

Context: [background]
Options: [list alternatives]

Evaluate: pros/cons, risks, team input, recommendation.
```

### 4. Knowledge Transfer
```
Document [system/feature] for team

Include: architecture, key decisions, gotchas, maintenance, troubleshooting.
```

### 5. Pair Programming Session
```
Plan pair programming for [task]

Setup: roles (driver/navigator), goals, time-boxing, breaks.
```

### 6. Architecture Decision Record
```
Create ADR for [decision]

Include: context, decision, consequences, alternatives, status.
```

### 7. Retrospective
```
Run retrospective for [sprint/project]

Discuss: what went well, what didn't, action items, improvements.
```

### 8. Mentoring Plan
```
Create mentoring plan for [junior developer]

Areas: [skills to develop]
Approach: resources, exercises, code reviews, pairing sessions.
```
