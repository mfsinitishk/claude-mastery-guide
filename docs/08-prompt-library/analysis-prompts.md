# Code Analysis Prompts

Concise prompts for code quality, complexity, and technical debt analysis.

### 1. Code Quality Analysis
```
Analyze code quality: SOLID violations, code smells, naming, duplication, complexity
Provide severity-ranked issues with refactoring recommendations.
```

### 2. Cyclomatic Complexity
```
Calculate cyclomatic complexity, flag functions >10, suggest simplifications.
```

### 3. Technical Debt Assessment
```
Assess technical debt: code quality, architecture, testing, documentation
Quantify debt, estimate effort, prioritize remediation.
```

### 4. Refactoring Priority
```
Prioritize refactoring by change frequency, bug density, complexity, criticality.
```

### 5. Dependency Audit
```
Audit dependencies: outdated packages, vulnerabilities, unused deps, license compliance.
```

### 6. Bundle Size Analysis
```
Analyze bundle size: package breakdown, tree-shaking, code splitting, lazy loading.
```

### 7. Legacy Code Analysis
```
Analyze legacy code: architecture, patterns, dependencies, risks, modernization opportunities.
```

### 8. Code Smell Detection
```
Detect: long methods, large classes, duplicated code, dead code, feature envy.
Provide refactoring suggestions.
```
