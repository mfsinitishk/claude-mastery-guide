## Resource Quality Standards

### Verification Process
All resources in this directory have been:
- ✅ Verified as actively maintained
- ✅ Tested for accuracy (as of May 2026)
- ✅ Rated by community feedback
- ✅ Categorized by difficulty level
- ✅ Assessed for value/cost ratio

### Rating System
- **5 Stars:** Exceptional quality, highly recommended
- **4 Stars:** High quality, recommended
- **3 Stars:** Good quality, useful
- **2 Stars:** Acceptable, limited use
- **1 Star:** Poor quality, not recommended

### Update Frequency
- **Official Resources:** Reviewed monthly
- **Community Resources:** Reviewed quarterly
- **Archived Content:** Flagged if >18 months old
- **Broken Links:** Reported and removed

## Contributing to Resources

### How to Suggest Resources
1. Fork the repository
2. Add resource to appropriate category
3. Include all required fields:
   - Title and description
   - Author/creator
   - Date/last updated
   - Difficulty level
   - Direct link
   - Rating (if available)
4. Submit pull request

### Resource Submission Criteria
**Must Have:**
- Publicly accessible
- High quality content
- Relevant to Claude AI
- Updated within 18 months (unless historical)
- Clear author/creator

**Bonus Points:**
- Free or affordable
- Comprehensive coverage
- Practical examples
- Community-tested
- Multiple formats
